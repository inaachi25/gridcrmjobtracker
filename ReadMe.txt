GRID — Personal CRM & Job Application Tracker
1. Project Overview

Grid is a personal web-based Job Application Tracker + CRM tool designed to help individuals systematically manage job applications, professional contacts, and career resources in one place.

2. Problem Statement
- Job hunting today is fragmented:
- Job applications are scattered across platforms
- Contacts from LinkedIn, Facebook, and email are hard to track
- Follow-ups are forgotten
- Useful resources are saved in random bookmarks or notes

3. Goals & Objectives
Primary Goals
- Track job applications clearly and visually
- Maintain a personal CRM for hiring managers, recruiters, and connections
- Store and organize email addresses for faster applications
- Keep all career-related resources in one place

MVP Includes
✅ User authentication
✅ Job application CRUD
✅ Kanban + table view
✅ Contact CRM CRUD
✅ Link contacts to jobs
✅ Email storage for easy applying
✅ Resources (links-only section)
✅ Basic dashboard
✅ Notes system
